# 宠物使用工具提示词模板

This skill generates high-converting TikTok pet product video scripts based on a 5-layer director-level teardown framework, specializing in the "ASMR Decompression" style.

## When to Use
- The user asks to write a TikTok script for a pet product (e.g., grooming tools, cleaning brushes).
- The user requests a video script using the 5-layer teardown structure.
- The user wants to replicate the "British Countryside ASMR" or similar strong visual Demo video framework.

## Steps
Always format the output strictly following this structure:

### 第一步：视频总结（3句话） (Video Summary)
Provide 3 concise sentences outlining:
1. Core visual hook and setting.
2. Emotional arc presentation.
3. Key conversion design (how the contrast breaks buying barriers).

### 第二步：逐层展开 (Layer-by-Layer Breakdown)
**第一层：结构层 (Structure Layer)**
- 识别视频的整体叙事骨架 (Identify narrative skeleton: Hook -> Demo -> Proof).
- 列出每个段落的时间节点和时长 (List timestamps and durations).
- 计算各段占总时长的比例 (Calculate percentage of total duration).
- 判断属于哪种结构类型 (Identify the structure type, e.g., 痛点解决/强视觉Demo型).

**第二层：情绪层 (Emotion Layer)**
- 前3秒触发了观众什么心理本能 (Identify the psychological trigger in the first 3 seconds).
- 用一条箭头链表示完整情绪弧线 (Map the emotional arc with arrows).
- 逐一标注每个情绪转折点 (Annotate emotional turning points with timestamps).
- 指出整条视频情绪最高峰在哪一秒，触发原因是什么 (Pinpoint the emotional climax second and its trigger).

**第三层：镜头层 (Camera Layer)**
- **CRITICAL:** Use full-paragraph, itemized formatting. **NEVER use tables.**
- Break down into appropriate shots (e.g., Hook, Demo A, Demo B, Proof).
- For each shot, include these exact bullet points:
  - 时间段 (Time segment)
  - 景别 (Shot type)
  - 运镜 (Camera movement)
  - 画面描述 (Visual description)
  - 口播/字幕 (Voiceover/Subtitles - smooth, natural pacing)
  - 结构标签 (Structure tag)
  - 镜头目的 (Shot purpose)
  - 演员表演指导 (Acting direction)
  - 灯光建议 (Lighting advice)
  - 情绪节拍 (Emotional beat)
  - 拍摄建议 (Shooting advice)

**第四层：语言层 (Language Layer)**
- 台词风格 (Dialogue style).
- 数字/价格冲击 (Number/price impact, or visual alternative).
- 关键词分析 (Keyword analysis).
- CTA话术 (CTA phrasing).

**第五层：转化层 (Conversion Layer)**
- CTA指向什么具体动作 (CTA specific action).
- 用了哪些转化触发器 (Conversion triggers used).
- 这条视频主要破除的“购买壁垒”是什么 (Main buying barrier broken).
- 视频是如何一步步击穿这个壁垒的 (Step-by-step breakdown of how the barrier is shattered).

### 第三步：可复用框架 (Reusable Framework)
Provide the framework template:
- 结构模板名称 (Framework name)
- 适用产品 (Suitable products)
- 时间分配 (Time allocation)
- 情绪弧线 (Emotion arc)
- 核心公式 (Core formula)
- 复用建议 (Reuse advice)

## Gotchas
- DO NOT use Markdown tables for the third layer (镜头层). Use strictly bullet points and paragraphs.
- Ensure Voiceover (VO) descriptions include notes for natural pauses and conversational pacing.
- Emphasize visual ASMR cues, satisfying product demonstrations, and emotional feedback loops (like a pet's positive reaction).
