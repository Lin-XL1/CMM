# 操作工具集

一个个人工作流工具集，包含两个部分：

1. **文件重命名工具** —— 按创建日期排序批量重命名文件的 Python 脚本。
2. **AI 视频提示词模板** —— 面向 TikTok 跨境电商的导演级 AI 视频生成提示词模板（Skill）。

---

## 1. 项目解决什么问题

- **文件乱序问题**：相机、手机、截图等文件默认按名称排列，无法体现拍摄/创建先后顺序。本工具可将文件夹内的文件**按创建日期（birthtime）排序**，批量重命名为 `1.xxx`、`2.xxx`、`3.xxx`……，让顺序一目了然。
- **视频脚本难产问题**：跨境电商（TikTok）产品视频需要专业的镜头语言与本土化口播，普通用户难以写出高质量、可稳定复用的 AI 视频提示词。本项目提供**导演级 5 段结构化模板**，直接生成可用于即梦（Jimeng）/ Sora 等 AI 视频生成工具的提示词。

---

## 2. 主要功能

### 2.1 按创建日期排序重命名（`按创建日期排序重命名.py`）

- 读取指定文件夹，自动跳过 `.DS_Store` 与子文件夹。
- 按文件**创建时间**（`st_birthtime`）升序排列，同时间按名称大小写不敏感排序。
- 批量重命名为 `1`、`2`、`3`……（保留原文件后缀名）。
- **冲突安全处理**：目标名称已被占用时，先给占用文件临时加 `-` 释放名称；名称大小写冲突自动规避。
- **二次确认**：重命名前打印完整预览，需输入 `Y` 确认后才会真正执行。
- **失败自动回滚**：执行中途出错时，自动恢复已重命名的文件。

### 2.2 AI 视频提示词模板（Skill）

| 模板文件 | 适用产品 | 说明 |
| --- | --- | --- |
| `headlamp-prompt-template.md` | 头灯 / 可穿戴照明产品 | 5 段导演级模板（参考拆解 → 产品锁定卡 → 分镜脚本表 → AI 视频提示词 → 一致性核验清单），支持本土化场景与口播 |
| `pet-tool-prompt-template.md` | 宠物用品 / 强视觉演示产品 | 5 层 ASMR 拆解框架（结构层 / 情绪层 / 镜头层 / 语言层 / 转化层），输出 Hook→Demo→Proof 短视频脚本 |
| `solar-light-prompt.md` | 太阳能磁吸露营灯 / 工作灯 | 基于头灯模板生成的东南亚 TikTok 完整提示词示例（泰语口播） |

## 3. 安装方法

重命名工具**仅使用 Python 标准库**（`pathlib`、`itertools`、`os`、`sys`、`uuid`），**无需安装任何第三方依赖**。

**环境要求**：Python 3.9+（项目已附带 `.venv` 虚拟环境，版本 3.9.6）。

```bash
# 1. 克隆/进入项目目录
cd 操作

# 2.（可选）激活项目自带虚拟环境
source .venv/bin/activate
```

> 提示词模板为纯 Markdown 文件，直接阅读或配合 VS Code Skill 机制使用即可，无需安装。

---

## 4. 使用方法

### 4.1 按创建日期排序重命名

```bash
python 按创建日期排序重命名.py
```

启动后按提示输入目标文件夹地址（可带引号），脚本会：

1. 打印检测到的子文件夹数量（子文件夹不参与重命名）。
2. 打印**按创建时间排序的重命名预览**。
3. 询问是否确认：输入 `Y` 执行重命名，输入其他任意内容取消。

### 4.2 使用 AI 视频提示词模板

1. 将对应的 `.md` 模板复制为 Skill（或直接作为提示词参考）。
2. 告诉 AI 你的产品、目标市场与场景（例如「帮我为太阳能露营灯写泰国市场的 TikTok 视频提示词」）。
3. AI 按模板的固定结构输出完整提示词，可直接粘贴到即梦 / Sora 等 AI 视频生成工具中。

## 5. 输入输出示例

### 5.1 重命名工具

**输入**（文件夹内文件创建时间从早到晚）：

```
IMG_0023.jpg   （创建于 09:01）
IMG_0010.jpg   （创建于 10:15）
IMG_0057.jpg   （创建于 11:30）
```

**运行**：

```
$ python 按创建日期排序重命名.py
请输入文件夹地址：/Users/me/照片

按创建时间排序的重命名预览：
  1. IMG_0023.jpg  ->  1.jpg  (创建时间 1724302860.000)
  2. IMG_0010.jpg  ->  2.jpg  (创建时间 1724307300.000)
  3. IMG_0057.jpg  ->  3.jpg  (创建时间 1724311800.000)

确认重命名？输入 Y 继续，其他输入取消：Y
完成：已按创建时间将 3 个文件重命名。
```

**输出**（重命名后）：

```
1.jpg   （原 IMG_0023.jpg，创建时间最早）
2.jpg   （原 IMG_0010.jpg）
3.jpg   （原 IMG_0057.jpg，创建时间最晚）
```

### 5.2 提示词模板

以 `headlamp-prompt-template.md` 为例，输入产品需求后，模板会输出包含以下 5 个固定部分的结构化提示词：

```
01 - 参考拆解（规格 / 本土化场景 / 核心痛点 / 全局设定）
02 - 产品锁定卡（灯体基材 / 发光单元 / 控制区域 / 配色锁定 / 禁止项）
03 - 分镜脚本表（镜号 | 画面内容 | 核心动作 | 本土化口播 | 音效）
04 - AI 视频提示词（每镜的产品外观 / 物理动作 / 背景 / 构图 / 负面词）
05 - 一致性核验清单（视觉锚点 / 合成通道 / 动作绑定 / 负面词统一）
```

可直接复制其中的「04 - AI 视频提示词」部分到 AI 视频生成工具使用。
